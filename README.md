# 🛍️ Caixa Loja

## 📌 Projeto: Assistente de descontos progressivos

### ✅ Objetivo
Calcular descontos de forma rápida, simples e organizada, com base no valor gasto em uma compra.

### ⚠️ Observações
- Validação de entrada
- Valores negativos são rejeitados
- Descontos por faixa de valor
- Possibilidade de consultar vários valores em sequência

### 📝 Descrição
Este projeto foi desenvolvido em Python para calcular descontos progressivos conforme o valor gasto em uma compra. O programa recebe o valor informado pelo usuário, valida a entrada e, de acordo com a faixa de valor, aplica o percentual de desconto adequado.

### 🔧 Funcionalidades
- Leitura do valor gasto pelo cliente
- Validação de entrada
- Tratamento de valores negativos e entradas inválidas
- Cálculo de desconto por faixa de valor
- Exibição do valor final a pagar
- Consulta de vários valores em sequência

### 💰 Exemplos de uso
Exemplo 1:
- Valor gasto: R$ 150,00
- Desconto: 5%
- Valor final: R$ 142,50

Exemplo 2:
- Valor gasto: R$ 250,00
- Desconto: 10%
- Valor final: R$ 225,00

Exemplo 3:
- Valor gasto: R$ 500,00
- Desconto: 15%
- Valor final: R$ 425,00
